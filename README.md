Analizador de Logs en Python

Script desarrollado en Python para analizar archivos de texto que contienen registros de eventos de una aplicación.

Características principales:

- Selección de archivos .txt mediante una ventana gráfica.
- Identificación de niveles de severidad: INFO, WARNING y ERROR.
- Validación de fechas (AAAA-MM-DD) y horas opcionales (HH:MM:SS).
- Detección de registros mal formateados o incompletos.
- Generación de estadísticas y resumen de eventos en consola.

Ejecución: python analizador_logs.py
